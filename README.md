# ResolveIT

ResolveIT is a Flask-based IT Help Desk Ticketing System that allows users to submit technical support requests and enables admins to track, prioritize, update, and resolve tickets through a database-backed dashboard.

## Features

- Submit IT support tickets
- Save tickets using SQLite
- View all tickets in an admin dashboard
- Search tickets by requester name
- Filter tickets by status and priority
- View full ticket details
- Update ticket status
- Add resolution notes
- Delete tickets
- Dashboard metric cards
- Modern responsive UI

## Tech Stack

- Python
- Flask
- SQLite
- HTML
- CSS
- Git & GitHub


## How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/akshakhdg/ResolveIT.git
```

2. Navigate into the project folder:

```bash
cd ResolveIT
```

3. Install dependencies:

```bash
pip install -r requirements.txt
```

4. Run the Flask app:

```bash
python3 app.py
```

5. Open the app in your browser:

```text
http://127.0.0.1:5001
```
